# Challenge1 - Marks Calculator For Students.

PROBLEM Statement:
write a C program to read the marks of a student obtained in five subjects and calculate (display) the total marks, average marks and percentage.

Algorithm:
1. Start
2. Create variables for 5 subject marks, totalmarks, average, percentage.
3. Read the marks of 5 subjects by using scanf function.
4. Calculate the totalmarks = s1 + s2 + s3 + s4 + s5.
5. Calculate the average = totalmarks/5.
6. Calculate the percentage = (totalmarks/500)*100.
7. Print totalmarks,average and percentage.
8. Stop
